# 商标素材来源

所有商标权利属于各品牌持有人。素材仅供在自己的照片上制作个人展示；若用于商业传播，请自行核查相关品牌的商标使用要求。脚本按 EXIF 文字匹配品牌，不对品牌标志做图像识别。

| 品牌 | 素材来源 |
| --- | --- |
| Nikon | [Nikon 官方品牌标志](https://www.nikon.com/company/corporate/brand/brand_symbol/)；从官方 SVG 提取字标并生成黑、白版本。 |
| Canon | [Canon 官方企业标志](https://global.canon/en/corporate/logo/)。 |
| Apple/iPhone | macOS 已安装的 Apple SF 字体中苹果符号；本地转成透明 PNG。 |
| Sony、Kodak、Panasonic、DJI、Fujifilm、Leica | [Simple Icons](https://github.com/simple-icons/simple-icons) 16.35.0 的相关品牌 SVG，经本地渲染成 PNG；Leica 使用红底白字。 |
| Sigma、Insta360、Panavision、Ricoh、GoPro、Zeiss、Olympus、Polaroid、ARRI、Hasselblad | 对应品牌的 [Wikimedia Commons](https://commons.wikimedia.org/) SVG 字标，经本地渲染成 PNG；部分深色字标另制作白色版本。 |

素材文件夹中保留了 Nikon 官方 SVG 和提取的 Nikon 字标 SVG。Photoshop 使用的商标均有黑白透明 PNG 两版。Leica、ZEISS 的单色版保留字标字形，避免将原彩色标志的实底直接涂成纯色块。
